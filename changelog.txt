	- [carttool.py] Add -e,--erase option to perform a chip erase
	- [carttool.py] Add a way to skip the automatic chip erase when

	- [carttool.py] Add a way to skip mapper detection / size
	  detection for dumping, programming and blank-checking
	- [carttool.py] Add --rawcommand option, to send manual commands to the programme
	- [carttool.ph] Add --file_start_offset and --file_read_size, to allow
	  programming with data embedded within a larger file.
